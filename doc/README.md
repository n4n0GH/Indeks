# Documentation

| Where | What | For whom |
| --- | --- | --- |
| [`manual/`](manual/) | The manual, one Markdown file per chapter; built into `Indeks-Manual.pdf` | People who use Indeks |
| [`developer/`](developer/) | How Indeks is built: architecture, database, development, how the documentation is kept | People who change Indeks |
| [`tools/`](tools/) | The program that makes the PDF of the manual | — |

The manual is opened in Indeks with *Indeks Manual* (`F1`).

Both are changed together with the code. A change that people who use Indeks can see or feel
is not done until the manual says so; see
[developer/documentation.md](developer/documentation.md).
